# PRD: Paytm Merchant Offer Loop MVP

## 1. Product Summary

Build a mock Paytm merchant web app that uses a merchant’s past transaction history to:

1. Analyze customer purchase behavior.
2. Segment/rank customers.
3. Let merchant create an offer.
4. AI/template drafts campaign copy.
5. Merchant approves campaign.
6. Offer is sent in mock Paytm chat/conversation.
7. Customer redeems through coupon during mock payment.
8. Dashboard proves actual sale/redemption happened.

Core idea:

```text
Merchant offer → AI drafts campaign → Matches audience → Merchant approves → Sent to customers → Redemption tracked
```

---

# 7. Customer Metrics Logic

For each merchant-customer pair:

```text
frequency = count(successful transactions)
total_spend = sum(amount)
avg_spend = total_spend / frequency
last_txn_date = latest successful txn date
recency_days = demo_today - last_txn_date
```

Use fixed demo date for stable results:

```text
DEMO_TODAY = 2026-02-01
```

---

# 8. Customer Segments

Customers can have multiple tags.

| Segment | Rule |
|---|---|
| One-time | frequency == 1 |
| Loyal | frequency >= 5 |
| Dormant | recency_days >= 45 |
| High Value | total_spend >= 75th percentile of merchant customers |
| Regular | none of the above |

Example:

```text
C001 → Loyal, High Value
C010 → Dormant
C022 → One-time
```

Primary display priority:

```text
Dormant > High Value > Loyal > One-time > Regular
```

# 13. Coupon Logic

Generate unique coupon per customer.

Format:

```text
PTM-{merchant_id}-{campaign_number}-{customer_id}
```

Example:

```text
PTM-M001-001-C045
```

Validation rules:

Coupon is valid only if:

1. Coupon exists.
2. Belongs to same customer.
3. Belongs to same merchant.
4. Campaign status is SENT.
5. Coupon not already redeemed.
6. Current date <= expiry date.
7. Bill amount >= minimum bill amount.

# 15. Dashboard Metrics

For each campaign:

```text
sent_count = number of campaign recipients
redeemed_count = number of valid redemptions
redemption_rate = redeemed_count / sent_count
campaign_revenue = sum(gross_bill_amount)
discount_cost = sum(discount_amount)
estimated_profit = campaign_revenue * margin_pct / 100 - discount_cost
```

Example:

```text
Sent: 80
Redeemed: 14
Redemption Rate: 17.5%
Revenue: ₹7,400
Discount Cost: ₹700
Estimated Profit: ₹1,150
```

This supports the USP:

```text
Proves the sale happened, not guessed from clicks.
```
